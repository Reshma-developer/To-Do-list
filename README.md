# React Todo App

A simple and responsive Todo List application built using React.js. This project allows users to add and delete tasks dynamically.

---

## Features

- Add new tasks
- Delete tasks
- Dynamic task rendering
- Simple and clean UI
- React state management using useState

---

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS

---

## Purpose of Project

This project was created to practice React concepts like:
- useState
- Event handling
- Array mapping
- Dynamic UI updates
